# HVA–NQ52

Nền tảng số hỗ trợ tự báo cáo, tự đánh giá và theo dõi hiệu quả thực hiện nhiệm vụ hằng tháng của Trường THPT Hòa Vang. Bản thử nghiệm, chưa nghiệm thu chấm điểm hoặc xếp loại chính thức.

## Nhánh main
- index.html: giao diện chính, kết nối Backend NQ52.
- NQ52_CuocHop.html: trang xem trước nghiệp vụ họp đánh giá.
- assets/: nhận diện nhà trường.
- backend/: các module Google Apps Script độc lập với EDOS. README trong backend là tài liệu lịch sử cần cập nhật theo xác thực LOCAL_PILOT, không dùng hướng dẫn Firebase cũ để triển khai.

## Mã nguồn tham chiếu
Nhánh [nq52-original-html](https://github.com/nvthahv03-cell/HVA-NQ52/tree/nq52-original-html) giữ nguyên ba HTML gốc và các file trước khi dọn kho. Không đưa các HTML còn gọi Backend EDOS vào website đang vận hành.

Không đưa dữ liệu nhân sự, mật khẩu, token hoặc thông tin cấu hình riêng tư lên GitHub.
